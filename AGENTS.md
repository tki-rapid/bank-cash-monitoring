# Bank Cash Monitoring Agent Rules

- This is a standalone PT TKI financial monitoring application.
- Never store, log, or commit bank passwords, OTPs, CAPTCHA values, cookies, or session data.
- Bank portal automation is read-only and human-in-the-loop.
- Use strict TypeScript and validate all API input with Zod.
- Use integer IDR amounts; never use floating-point money values.
- Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` before declaring completion.
